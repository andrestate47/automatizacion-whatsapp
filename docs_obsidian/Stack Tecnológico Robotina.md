# Stack Tecnológico Robotina

El proyecto utiliza un conjunto moderno y reactivo de herramientas orientadas a velocidad y actualizaciones en vivo sin recargas.

## Frontend
- **Framework:** React 19 + TypeScript.
- **Bundler:** Vite (compilado ultrarrápido).
- **Enrutamiento:** React Router DOM v6.
- **Visualización de Datos:** Recharts (para analíticas y gráficas del módulo de BI).
- **Estilos:** CSS Modules + Variables Nativas (Soporte nativo Dark Mode, crítico para el KDS).
- **Extras:** `qrcode.react` para integraciones y `canvas-confetti` para gamificación/éxitos.

## Backend y Base de Datos
- **Proveedor:** Supabase.
- **Base de Datos:** PostgreSQL (pg).
- **Sincronización:** Supabase Realtime Channels (WebSockets).

## Automatización y Backend de IA
- **Plataformas de Flujo:** n8n (indicado por `expanded_workflow.json` y webhooks) y Evolution API.
- **IA:** OpenAI (Configurado vía API Keys en los tenants).
- **Canales Mensajería:** WhatsApp Business API (Meta Graph API) e Instagram.
